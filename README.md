# Виртуальный тур — 46 панорам

Статический сайт на библиотеке [Marzipano](https://www.marzipano.net/) (v0.10.2, лежит локально в `vendor/`, интернет не нужен).

## Как открыть

Двойной клик по **`Запустить тур.command`** — поднимется локальный сервер и откроется браузер.

Просто открыть `index.html` двойным кликом не получится: браузеры блокируют загрузку текстур WebGL по протоколу `file://` (политика CORS). Нужен любой веб-сервер — локальный или хостинг.

Альтернатива вручную:

```bash
cd путь/к/папке/tour
python3 -m http.server 8123
# затем открыть http://localhost:8123
```

## Загрузка на хостинг

Папку целиком (`index.html`, `css/`, `js/`, `vendor/`, `img/`, `tiles/`) можно положить на любой статический хостинг: Netlify, Vercel, GitHub Pages, Timeweb, обычный nginx. Никакого бэкенда не требуется. Общий вес — около 78 МБ.

## Как устроены переходы

Точки съёмки распознаны с файла `Map_Numb_White.jpg` — все 46 маркеров, номера сопоставлены автоматически и проверены наложением на план.

Связи между сценами построены не по прямой линии, а по **проходимой сети**: по плану выделены мощение, дорожки и проезды, между точками ищется кратчайший пеший путь. Соседями становятся точки, между которыми нет другой точки съёмки по дороге. У каждой сцены от 2 до 5 переходов.

Направление стрелки — это азимут первого участка реального пути, поэтому стрелка ведёт вдоль дорожки, а не сквозь здание.

**Ориентация панорам откалибрована** и проверена на трёх сценах (34, 39, 45): у этих рендеров направление взгляда `yaw = 0` совпадает с направлением «вверх» на плане. Поэтому компас в левом нижнем углу и сектор обзора на миникарте показывают реальное направление.

## Кнопка перехода

Одна авторская SVG-иконка на все переходы: тёмное стекло, тёплая металлическая обводка, шеврон направления и пульсирующее кольцо вокруг. Размер одинаковый у всех кнопок независимо от расстояния — разной остаётся только высота посадки над мощением: чем ближе точка, тем ниже кнопка в кадре.

Иконка всегда развёрнута к зрителю: при повороте камеры она смещается вместе со своей точкой, но не наклоняется и не искажается.

## Как кнопки держатся за панораму

Штатный слой хотспотов Marzipano здесь не используется — вместо него свой, в `tour.js`. Причин две.

Во-первых, Marzipano пересчитывает положение хотспотов в событии `afterRender`, то есть уже после отрисовки кадра. Здесь позиции считаются в `beforeRender` — тем же значением `view`, которое через мгновение уйдёт в рендер, поэтому стрелка и панорама идут кадр в кадр. Проверено замером во время перетаскивания: расхождение с эталонной проекцией — сотые доли пикселя.

Во-вторых, положение считается собственной проекцией, поэтому кнопка доезжает до самой кромки экрана и уходит за неё целиком, а не пропадает заранее.

Ни на одном элементе кнопки нет CSS-переходов и анимаций положения: любая такая анимация означала бы, что иконка едет к новой точке вдогонку.

## Управление

- Мышь / палец — осмотреться, колесо — зум
- Клик по стрелке или по точке на плане — переход
- `Shift` + `←` / `→` — предыдущая / следующая точка
- `⤢` на карте — увеличить план (появятся номера точек)
- `–` — свернуть карту, значок в углу вернёт её
- `◎` — автовращение, `⛶` — полный экран
- Ссылка вида `index.html#12` открывает тур сразу на нужной точке

## Если стрелка стоит не там

Встроен режим ручной правки — клавиша **`E`**.

1. Нажмите `E`, откроется панель слева.
2. Кликните по панораме там, где должна стоять стрелка, — панель покажет `yaw` и `pitch`.
3. Нажмите номер точки, к которой ведёт этот переход.
4. Соберите все правки и нажмите «Экспорт правок» — скачается `hotspot-edits.json`.

Значения из этого файла подставляются в `js/data.js`: находите нужную сцену по `id`, в её `links` — нужный `to`, и заменяете `yaw` и `pitch`.
